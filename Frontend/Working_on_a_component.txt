These are the steps to work on a component in angular

1.Create a component using the command "ng g c component-name"
2.In component.ts add all the libraries which are added in the dashboard component,and update the imports array, also make it a standalone as done in dashboard component.
3.Copy the name of export class below for example "DashboardComponent" and paste it in imports array of app.component.ts
4.Also import the component from its class as done for the dashboard.
5.Design the page using html and css,write the logic such as data entry or button clicking in component.ts 
6.No need to work in component.spec.ts
7. add the tags inside app.component.html

Note: All of this is for a single component which is work in progress
Avoid doing changes in files other than your components.
